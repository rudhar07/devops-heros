## Why LocalStack

I have no AWS account, and the homework only needs to show that Terraform and the AWS APIs work. So I emulated AWS with LocalStack in Docker, which costs nothing and needs no real credentials. Terraform and the AWS CLI talk to `http://localhost:4566` with the fake keys `test`/`test`. The Terraform code has a `use_localstack` variable (default `true`), and setting it to `false` sends the same code to real AWS. I pinned image `localstack/localstack:4.14.0`, the last free community tag. The newer `2026.x`/`latest` tags are LocalStack's unified image, which needs an auth token.

What LocalStack community does **not** do (and where it matters below): it doesn't enforce IAM or bucket policies, EC2 instances are API records and not real VMs, and RDS isn't available at all.

## Task 1: Terraform S3 demo

Full write-up: **[terraform-s3-demo/README.md](terraform-s3-demo/README.md)**.

I built an S3 bucket with versioning, SSE-S3 encryption, a full public access block and tags (4 Terraform resources), ran the whole workflow, checked the result with `aws s3api`, and destroyed it.

```text
$ terraform plan -no-color -out=tfplan
Plan: 4 to add, 0 to change, 0 to destroy.

$ terraform apply -no-color tfplan
Apply complete! Resources: 4 added, 0 changed, 0 destroyed.
bucket_arn = "arn:aws:s3:::rudhar-session18-tf-demo-10143"
versioning_status = "Enabled"

$ aws --endpoint-url http://localhost:4566 s3api get-bucket-versioning --bucket rudhar-session18-tf-demo-10143
{
    "Status": "Enabled"
}

$ terraform destroy -auto-approve -no-color
Destroy complete! Resources: 4 destroyed.
```

The README explains each command and its output: the state file, `+ ~ - -/+` (each produced for real), `(known after apply)`, and why destroy runs in reverse order.

My files differ from the instructor's `terraform-s3-demo/` in a few ways. The `terraform {}` block is in `provider.tf`, as the spec asks for exactly six files. The bucket name is set in `terraform.tfvars` instead of a default. And the bucket has versioning, encryption and a public access block on top of plain tags.
