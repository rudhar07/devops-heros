### Access the app through the Ingress (path-based routing on host yatri.local)
$ curl -s -o /dev/null -w 'GET yatri.local/ -> HTTP %{http_code}\n' -H 'Host: yatri.local' http://localhost:30081/
GET yatri.local/ -> HTTP 200

$ sh -c 'curl -s -H '"'"'Host: yatri.local'"'"' http://localhost:30081/ | grep -o '"'"'<title>.*</title>'"'"''
<title>Welcome to nginx!</title>

$ curl -s -H 'Host: yatri.local' http://localhost:30081/api/
Yatri Backend API
=================
ENVIRONMENT     : production
LOG_LEVEL       : INFO
DEFAULT_CURRENCY: INR
POSTGRES_USER   : yatri_admin
POSTGRES_DB     : yatri_production_db

$ curl -s -H 'Host: yatri.local' http://localhost:30081/api/bookings
Yatri Backend API
=================
ENVIRONMENT     : production
LOG_LEVEL       : INFO
DEFAULT_CURRENCY: INR
POSTGRES_USER   : yatri_admin

# /api/... goes to the Python backend (it prints values injected from the ConfigMap and the Secret),
# everything else goes to nginx. The rewrite-target /$2 strips the /api prefix before the request reaches the backend.
$ curl -s -o /dev/null -w 'unknown host -> HTTP %{http_code}\n' -H 'Host: other.local' http://localhost:30081/
unknown host -> HTTP 404

$ curl -s -o /dev/null -w 'no Host header match (plain localhost) -> HTTP %{http_code}\n' http://localhost:30081/
no Host header match (plain localhost) -> HTTP 404

$ sh -c 'curl -s --resolve yatri.local:30081:127.0.0.1 http://yatri.local:30081/api/ | head -3'
Yatri Backend API
=================
ENVIRONMENT     : production
